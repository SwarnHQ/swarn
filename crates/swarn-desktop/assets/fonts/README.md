# Fonts

Static instances cut from the variable fonts that Plexo ships
(`src/renderer/src/assets/fonts/*.woff2` in github.com/anmolkapil/plexo), with fontTools'
instancer and the name tables rewritten so each file reports a clean family name.

| Family | Weights | Upstream | License |
| --- | --- | --- | --- |
| Manrope | 400, 500, 600, 700 | github.com/sharanda/manrope | SIL OFL 1.1 |
| Roboto Mono | 400, 500, 600 | github.com/googlefonts/RobotoMono | SIL OFL 1.1 |

The full license text ships next to the fonts, as the OFL requires: `OFL-Manrope.txt` and
`OFL-RobotoMono.txt`.
